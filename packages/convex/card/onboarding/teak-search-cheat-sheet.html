Teak field guide

Find anything,
even by color.

Teak reads every card you save: the colors in an image, the words in a voice memo, the text inside a PDF. Type into the search bar and mix any of these.

Search by look

Colors and styles come from the image itself. No tagging needed.

orange tealA dominant color
#FF6B6BAn exact hex match
minimal darkA visual style
pastel vibrantMood of the palette

Narrow it down

Filters become removable pills as you pick them.

type:imageOnly one card type
#brandingCards with that tag
site:dribbble.comLinks from one site
folder:"Moodboard"Inside a folder
is:favOnly favorites

Find it by when

Dates match when you saved the card.

todaySaved today
this weekThe last few days
januaryA month
last yearA whole year

Find it by words

Titles, notes, AI summaries, transcripts and PDF text are all searchable.

button hoverWords anywhere in a card
"design system"The exact phrase
favoritesJump to a view
trashOpen Trash

Put them together

Every filter applies at once. Save any search as a smart folder and it keeps filling itself as you save.

type:image orange
Warm references for a moodboard.
#typography this week
Type ideas you saved lately.
site:github.com "design system"
GitHub links about design systems.
