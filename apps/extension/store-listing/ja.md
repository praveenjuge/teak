# Teak: Chrome ウェブストアと AMO の掲載文（日本語）

## 概要

あなた専用のナレッジハブです。Web コンテンツを手軽に保存、整理して、もう一度見つけられます。

## 説明

Teak は、アイデアやインスピレーションを集め、覚えておき、もう一度見つけるためのあなた専用のナレッジハブです。この拡張機能を使うと、Web で見つけたものをワンクリックで Teak のライブラリに保存できます。

- 開いているページを保存できます。Teak のポップアップを開くとページが保存されます。保存後すぐにタグやメモを追加できます。
- 右クリックで、ページ、画像、動画、リンク、選択したテキストを保存できます。テキストには元のページへのリンクが残ります。
- Alt+Shift+S を押すと、ポップアップを開かずに現在のページを保存できます。ページがすでに Teak にある場合は、ツールバーのアイコンでわかります。
- 保存したページは、表示されたままの状態で Teak が非公開のコピーとして保管します。元のページがなくなっても読めます。
- ポップアップから 100 MB までのファイルをアップロードできます。
- アドレスバーからライブラリを検索できます。「teak」と入力し、スペースに続けて探しているものを入力します。
- 対応している SNS やデザインサイトの投稿を、各投稿のボタンから保存できます。

Teak アカウントでサインインしてお使いください。無料プランでは 200 枚までカードを保存でき、Teak Pro ではカードを無制限に保存できます。
