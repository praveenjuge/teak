# Teak: Chrome 웹 스토어 및 AMO 등록 정보 (한국어)

## 요약

나만의 지식 허브입니다. 웹 콘텐츠를 손쉽게 저장하고 정리하며 다시 찾아볼 수 있습니다.

## 설명

Teak은 아이디어와 영감을 모으고, 기억하고, 다시 발견하기 위한 나만의 지식 허브입니다. 이 확장 프로그램은 웹에서 찾은 것을 클릭 한 번으로 Teak 라이브러리에 저장합니다.

- 보고 있는 페이지를 저장합니다. Teak 팝업을 열면 페이지가 저장됩니다. 저장한 직후 태그와 메모를 추가할 수 있습니다.
- 마우스 오른쪽 버튼을 클릭해 페이지, 이미지, 동영상, 링크 또는 선택한 텍스트를 저장합니다. 텍스트에는 원래 페이지로 가는 링크가 함께 저장됩니다.
- Alt+Shift+S를 누르면 팝업을 열지 않고 현재 페이지를 저장합니다. 페이지가 이미 Teak에 있으면 툴바 아이콘에 표시됩니다.
- 팝업에서 최대 100MB의 파일을 업로드합니다.
- 주소 표시줄에서 라이브러리를 검색합니다. "teak"을 입력하고 한 칸 띄운 다음 찾는 내용을 입력합니다.
- Instagram, Pinterest, X, Hacker News, Sidebar, HeyDesigner의 게시물을 각 게시물의 버튼으로 저장합니다.

시작하려면 Teak 계정으로 로그인합니다. 무료 요금제는 카드 200개까지 저장할 수 있으며, Teak Pro는 카드를 무제한으로 저장합니다.
