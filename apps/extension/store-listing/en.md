# Teak: Chrome Web Store and AMO listing (English)

## Summary

Your personal knowledge hub. Save, organize, and rediscover web content effortlessly.

## Description

Teak is your personal knowledge hub for collecting, remembering, and rediscovering ideas and inspiration. The extension saves what you find on the web to your Teak library in one click.

- Save the page you're on: open the Teak popup and the page is saved. Add tags and a note right after saving.
- Right-click to save a page, an image, a video, a link, or selected text. Text keeps a link to the page it came from.
- Press Alt+Shift+S to save the current page without opening the popup. The toolbar icon shows when a page is already in Teak.
- Upload a file of up to 100 MB from the popup.
- Search your library from the address bar: type "teak", then a space, and what you're looking for.
- Save posts from Instagram, Pinterest, X, Hacker News, Sidebar, and HeyDesigner with a button on each post.

Sign in with your Teak account to start. The free plan holds 200 cards; Teak Pro has unlimited cards.
