# Test plans

Markdown test plans written by the `playwright-test-planner` agent live here.
The `playwright-test-generator` agent turns each plan into specs under
`src/tests/*.e2e.ts`, starting from `src/tests/seed.e2e.ts`.

Plans describe user-observable behavior: what the user does and what they see.
Review generated specs against `.agents/testing.md` before merging.
