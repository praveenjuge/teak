Teak Desktop gives you a native macOS app with automatic updates and the same real-time sync as web and mobile.

<Badge variant="accent">macOS</Badge> <Badge>Apple Silicon</Badge>

## Requirements

- macOS 13.0 or newer
- Apple Silicon Mac (M1, M2, M3, or newer)
- Internet connection for sign-in and sync

## Install

<Steps>
  <Step title="Download">
    Download the latest macOS build from [GitHub Releases](https://github.com/praveenjuge/teak/releases/latest).
  </Step>
  <Step title="Open the disk image">
    Open the `.dmg` file.
  </Step>
  <Step title="Install">
    Drag **Teak.app** to **Applications**.
  </Step>
  <Step title="Launch">
    Launch Teak from Applications.
  </Step>
</Steps>

Releases are signed and notarized. If Gatekeeper blocks the first launch, choose **Open Anyway** under **System Settings → Privacy & Security**, then relaunch.

## Sign In

Desktop sign-in opens a secure browser-based authentication window. Approve access
on the consent screen, then the app returns you automatically after login. The
desktop app keeps its own session, so signing out on desktop does not sign you
out of Teak in your browser.

## Settings

Open **Teak menu → Settings…** for **Appearance** (**Auto** follows macOS), **Sign Out**, and shortcuts to account, billing, API keys, and import/export in the web app.

## Updates

Teak checks for updates on each launch via GitHub Releases, showing download progress and prompting to restart when ready. If a check fails, Teak keeps running and retries on the next launch.

To update manually or recover a failed install, quit Teak, download the latest release from [GitHub Releases](https://github.com/praveenjuge/teak/releases/latest), replace **Teak.app** in Applications, and relaunch.

## Troubleshooting

<Accordion>
  <AccordionItem title="An update does not apply">
    - Relaunch the app and wait for the update check.
    - Confirm GitHub Releases is reachable from your network.
    - Install the latest release manually from GitHub.
  </AccordionItem>
  <AccordionItem title="Still stuck?">
    Reach out via [Support](/docs/support).
  </AccordionItem>
</Accordion>
