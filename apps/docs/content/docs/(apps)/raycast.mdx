### Using an API key

Paste a key from **Settings → Integrations → API keys** into the extension preferences; it overrides browser sign-in. See [Authentication](/docs/api#authentication) for key limits and rotation.

## Commands

- **Quick Save**: a form for text or a link, with optional tags and note.
- **Save to Teak**: save text or a link in one step, with optional tags and note arguments. As a [fallback command](https://manual.raycast.com/fallback-commands), it saves a root search that has no results.
- **Save Clipboard**: save the clipboard, including a copied file or image, without a prompt.
- **Save Selected Text**: save text selected in any app; good with a hotkey.
- **Save Current Browser Tab**: needs the [Raycast Browser Extension](https://www.raycast.com/browser-extension).
- **Save Finder Selection**: upload selected Finder files, up to 100 MB each.
- **Search Cards**: find and open cards, with a type menu beside the search bar.
- **Favorites**: your favorite cards.
- **Browse Folders**: folders and smart folders, and their cards.
- **Browse Tags**: every tag with its card count; open one to search it, or rename, merge or delete it from its actions.
- **Random Cards**: 20 shuffled cards to **Keep** or **Archive Card**; **Shuffle Again** (⌘R) deals a new set.
- **Find Similar Cards**: paste a card ID or Teak link to see the closest cards in meaning.

Re-saving a link says **Already saved** and moves that card to the top instead of duplicating it (see [Saving something again](/docs/features#saving-something-again)).

### Search filters

Type these in **Search Cards** or **Favorites**, or pick them from the **Filters** actions. Most match the web ([Smart search](/docs/features#smart-search)); `hue:`, `style:`, `after:`, `before:` and `sort:` are Raycast-only.

| Filter | Example |
| --- | --- |
| Exact phrase | `"total due"` (a quoted word like `"fav"` is searched, not used as a filter) |
| Type | `type:image` |
| Tag | `tag:design` or `tag:"design systems"` |
| Favorites | `fav` |
| Archive | `is:archived` |
| Done or still to do (links) | `is:done`, `is:todo` |
| Folder | `folder:"Reading list"` |
| Similar to a card | `like:<card ID>` |
| Image mood | `mood:"moody brutalist"` |
| Words inside images and scans | `text:"total due"` |
| Price | `price:<100` (also `>`, `<=`, `>=`, `=`) |
| Trash | `trash` |
| Color family | `hue:blue` |
| Visual style | `style:minimal` |
| Exact color | `#112233` |
| Saved on or after / before | `after:2026-09`, `before:2026-10-15` |
| Oldest first, or shuffled | `sort:oldest`, `sort:shuffle` |

**Filters** also has **Show Archive**, **Filter by Progress** (Done or To Do) and **Shuffle** under **Sort Results**. **Save Search as Smart Folder…** saves the typed search, except Trash, color, style and date filters. [Hidden cards](/docs/features#hidden-cards) show only when you search their tag.

### Card details and actions

A card shows its image or text, notes, summary, tags, file details, link facts, palette colors, transcript and linked cards. Raycast can't play video or audio or preview documents; use **Open File** (⌘⇧O) or **Open in Teak** (⌘O).

| Action | Shortcut |
| --- | --- |
| **Mark as Read** (or watched, bought and so on; again to undo) | ⌘⇧D |
| **More Like This** | ⌘⇧S |
| **Add to Folder…** | ⌘⇧F |
| **Archive** / **Unarchive** | ⌘⇧A |
| **Refresh Details** | ⌘R |
| **Edit Card**: notes, tags, text, quotes and palette colors | ⌘E |
| **Copy URL** (or the text, for a card without one) | ⌘⇧C |
| **Copy Teak Link** | ⌘⇧L |
| **Move to Trash** | ⌃X |
| In Trash: **Restore** / **Delete Forever** | ⌘⇧R / ⌃X |

Actions also include **Copy Content** and **Copy Color** (from a palette or image).

## AI tools

Teak's tools for [Raycast AI](https://www.raycast.com/ai):

| Tool | What it does |
| --- | --- |
| **Save to Teak** | Save a note or URL. |
| **Search Teak Cards** | Search by text, type, tags, folder, favorite, done and archive state, mood, similarity to a card, and sort order, including shuffle. |
| **Get Recent Teak Cards** | Fetch the newest cards without a query. |
| **Get Teak Card** | Fetch a card's full details by ID. |
| **List Teak Tags** | List tags with card counts. |
| **List Teak Folders** | List folders and smart folders with card counts. |
| **Toggle Favorite** | Favorite or unfavorite a card. Requires confirmation. |
| **Update Teak Card** | Add or remove tags, including Teak's, change notes, add or remove a palette's colors, mark a link done, archive a card, or add it to a folder. Requires confirmation. |

AI tools use the extension's sign-in; no setup needed.

## Sign out

**Sign Out** (⌘⇧X) is in any list's actions. It disconnects Raycast on every Mac; reconnecting can take about 15 minutes. If the saved sign-in already expired, only this Mac signs out, and Raycast says so; disconnect the others in **Settings → Security → Connected apps**.

## Troubleshooting

On **Connection unavailable**, check your connection and choose **Retry Connection**; your sign-in is kept.

If your sign-in expired or was disconnected, open any Teak command and sign in again. An invalid API key message applies only to a key set in preferences.
