### Using an API key

Prefer an API key? Paste one from **Settings → Integrations → API keys** into the extension preferences; it takes precedence over browser sign-in. See [Authentication](/docs/api#authentication) for key limits and rotation.

## Commands

- **Quick Save**: a form to type or paste text and links, with optional tags and a note.
- **Save to Teak**: save text or a link in one step, with optional tags and note arguments. It also works as a [fallback command](https://manual.raycast.com/fallback-commands), so pressing Enter on a root search with no results saves that query.
- **Save Clipboard**: save the clipboard with no prompt; a copied file or image is uploaded.
- **Save Selected Text**: save the text selected in any app. Pairs well with a hotkey.
- **Save Current Browser Tab**: needs the [Raycast Browser Extension](https://www.raycast.com/browser-extension).
- **Save Finder Selection**: upload the files selected in Finder, up to 100 MB each.
- **Search Cards**: find and open cards, with a type menu beside the search bar.
- **Favorites**: your favorite cards.
- **Browse Folders**: your folders and smart folders, and their cards.
- **Browse Tags**: every tag with its card count. Open one to search within it, or rename, merge or delete it from its actions.
- **Random Cards**: 20 shuffled cards. **Keep** moves on, **Archive Card** puts one away, and **Shuffle Again** (⌘R) deals a new set.
- **Find Similar Cards**: paste a card ID or Teak link to see the cards closest to it in meaning.

Saving a link you already have says **Already saved** and moves that card to the top instead of making a second one (see [Saving something again](/docs/features#saving-something-again)).

### Search filters

Type these into **Search Cards** or **Favorites**, or pick them from the **Filters** actions. Most work as on the web ([Smart search](/docs/features#smart-search)); `hue:`, `style:`, `after:`, `before:` and `sort:` are Raycast's own.

| Filter | Example |
| --- | --- |
| Exact phrase | `"total due"` (a quoted word like `"fav"` is searched, not used as a filter) |
| Type | `type:image` |
| Tag | `tag:design` or `tag:"design systems"` |
| Favorites | `fav` |
| Archive | `is:archived` |
| Done or still to do (links) | `is:done`, `is:todo` |
| Folder | `folder:"Reading list"` |
| Similar to a card | `like:<card ID>` |
| Image mood | `mood:"moody brutalist"` |
| Words inside images and scans | `text:"total due"` |
| Price | `price:<100` (also `>`, `<=`, `>=`, `=`) |
| Trash | `trash` |
| Color family | `hue:blue` |
| Visual style | `style:minimal` |
| Exact color | `#112233` |
| Saved on or after / before | `after:2026-09`, `before:2026-10-15` |
| Oldest first, or shuffled | `sort:oldest`, `sort:shuffle` |

**Filters** also has **Show Archive**, **Filter by Progress** (Done or To Do) and **Shuffle** under **Sort Results**. With a search typed, **Save Search as Smart Folder…** saves it; Trash, color, style and date filters can't be saved. [Hidden cards](/docs/features#hidden-cards) show only when you search their tag.

### Card details and actions

A card shows its image or text, notes, summary, tags, file details, link facts, palette colors, transcript and linked cards. Raycast can't play video or audio or preview documents; use **Open File** (⌘⇧O) or **Open in Teak** (⌘O) for those.

| Action | Shortcut |
| --- | --- |
| **Mark as Read** (or watched, bought and so on; again to undo) | ⌘⇧D |
| **More Like This** | ⌘⇧S |
| **Add to Folder…** | ⌘⇧F |
| **Archive** / **Unarchive** | ⌘⇧A |
| **Refresh Details** | ⌘R |
| **Edit Card**: notes, tags, text, quotes and palette colors | ⌘E |
| **Copy URL** (or the text, for a card without one) | ⌘⇧C |
| **Copy Teak Link** | ⌘⇧L |
| **Move to Trash** | ⌃X |
| In Trash: **Restore** / **Delete Forever** | ⌘⇧R / ⌃X |

**Copy Content** and **Copy Color** (any color from a palette or image) are in the actions too.

## AI tools

Teak exposes the following tools for [Raycast AI](https://www.raycast.com/ai):

| Tool                      | What it does                                                      |
| ------------------------- | ----------------------------------------------------------------- |
| **Save to Teak**          | Save a note or URL to your Teak library.                          |
| **Search Teak Cards**     | Search cards by text, type, tags, folder, favorite, done and archive state, mood, similarity to a card, and sort order, including shuffle. |
| **Get Recent Teak Cards** | Fetch the newest cards without a search query.                    |
| **Get Teak Card**         | Fetch the full details of a specific card by ID.                  |
| **List Teak Tags**        | List your tags with per-tag card counts.                          |
| **List Teak Folders**     | List your folders and smart folders with card counts.             |
| **Toggle Favorite**       | Favorite or unfavorite a card. Requires confirmation.             |
| **Update Teak Card**      | Add or remove tags, including Teak's, change notes, add or remove a palette's colors, mark a link done, archive a card, or add it to a folder. Requires confirmation. |

AI tools use the extension's sign-in; there's nothing else to set up.

## Sign out

Choose **Sign Out** (⌘⇧X) from the actions of any list. Signing out disconnects Raycast on every Mac it's installed on; reconnecting can take about 15 minutes. If the saved sign-in has already expired, Raycast signs out only this Mac and says so; disconnect the others in **Settings → Security → Connected apps**.

## Troubleshooting

If **Connection unavailable** appears, check your connection and choose **Retry Connection**. Your saved sign-in stays available.

If a command says your Teak sign-in has expired or was disconnected, open any Teak command and sign in with your browser again. A message about an invalid API key is only for an API key set in the extension preferences.
