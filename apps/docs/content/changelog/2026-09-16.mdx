description: The dedicated search and favorites API endpoints are removed in favor of filtered card listing.
type: changelog
date: "2026-09-16"
changelog:
  category: Improvements
---

- The dedicated API search and favorites endpoints are removed. Direct API integrations should use filtered card listing for the same results.
- The CLI, SDK, MCP tools, and Raycast extension already use filtered listing in 1.0.70 and later, so upgrading keeps most setups unchanged.
