## Writing notes

- Web and desktop notes now support headings, lists, tasks, quotes, code, and links while you write. Type `/` for formatting commands or select text for quick formatting.
- Your notes stay in Markdown. Existing tables, image references, and other unsupported formatting remain editable as text, with no changes until you edit.
