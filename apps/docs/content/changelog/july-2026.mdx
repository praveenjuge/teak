- **Teak CLI:** save, search, edit and organize cards from your terminal, with browser sign-in. See [CLI](/docs/cli).
- **Sign in with your browser** in Raycast, the CLI and MCP clients, so you no longer need to copy an API key. Existing keys keep working.
- **More file types:** upload source code, Markdown, Office documents, ZIP files, SVG, HEIC, animated GIF, Figma files and more, from every app.
- **ChatGPT:** add Teak as a connector to search and read your cards. See [AI agents](/docs/ai-agents).
- Import and export share one place in Settings, with live progress for both.
- Save any docs page as a PDF or EPUB from its page menu.

## For developers

- The API and MCP server moved to `teakvault.com/api` and `teakvault.com/mcp`. Old addresses and keys keep working.
- The API can upload files, MCP clients can browse, sync and bulk-edit cards, and the [API reference](/docs/api) is searchable, with code samples.
