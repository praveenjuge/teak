## Your library and imports

- Coming back from Settings keeps your library, search and unsaved note as you left them.
- Canceling an import stops it promptly. See [Import](/docs/import).
- Chrome keeps saves interrupted by an extension update so you can retry them. After updating Chrome or Safari, sign in to the extension again.

## Account and sign-in

- **Security** in Settings brings devices, connected apps and API keys together. Signing out a device or disconnecting an app cuts its access at once.
- Sign-in options that aren't available explain why.

## Apps and integrations

- AI agents in supporting browsers can search and read your cards from the Teak web app with no setup. See [In-browser tools](/docs/webmcp).

## For developers and self-hosters

- **Breaking:** the API's separate search and favorites endpoints are gone. Search and filter with the card list instead; the CLI, SDK, MCP and Raycast already do. See [API](/docs/api).
- Self-hosting locally takes one command. If you set custom API or MCP addresses, move them to one public address. See [Self-hosting](/docs/self-hosting).
